    How it works

    1. 1
      Host starts a room

      One person taps I’m hosting, picks a room name, and starts. TunnelX shows their Host address and a Copy invite button.

    2. 2
      Share the invite

      The host sends the copied message (or tells friends the address + room name). No ports or firewalls to configure for this step.

    3. 3
      Friends join, then everyone opens the game

      Joiners choose I’m joining, paste the host address, use the same room name, then open the game and pick LAN / local network multiplayer.
